# 选职 · 公考资料包分析器

本机运行的考试资料整理与岗位辅助初筛工具。上传职位表、公告、指南和专业目录，查看可追溯的条件判断、待核对项，并比较岗位。

当前重点验证广东省考。专业匹配已支持按考试范围导入结构化规则，尚未完成全国各省适配，也不能将初筛结果视为招录机关资格认定。

## 启动

第一次使用请看 **[新手安装与使用教程](docs/quick-start.md)**，从下载、安装到演示筛选逐步操作。

想让 AI 帮你安装？复制 **[AI 本地部署指令](docs/ai-local-setup.md)** 中的提示词，交给能操作你电脑终端和文件的 AI 助手。普通网页聊天只能指导你执行，不能直接安装。

需要 Python 3.9+；开发测试另需 Node.js 18+。不需要 AI 密钥、数据库或 Node 依赖安装。

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python server.py --open
```

Windows 将激活命令替换为 `.venv\Scripts\activate`。准备好依赖后，可以双击根目录的 Mac / Windows 启动器。Windows 尚未完成真机验收；旧 DOC 在 Mac 使用系统 `textutil` 读取，其他系统建议转存 DOCX。

按终端显示的本机地址打开；默认寻找 8765—8775 中可用的端口，或用 `--port 8789` 指定。服务只监听 `127.0.0.1`，不是公网部署方案。

## 使用

1. 上传一次考试的职位表、公告和指南；支持多文件及 ZIP。确认系统推断的考试归属，处理冲突或缺失项。
2. 填写自己的学历、专业等已知事实。未知保持留空；查看结果对应的原文、来源及判断范围。
3. 在结果区“快速缩小结果”隐藏三不限或不限专业，按备注状态/类别查看，或隐藏包含指定类别备注的岗位。清单先显示分类标签，原文可展开；这些筛选不改变资格结论。可加入岗位 PK、导出当前筛选 CSV；刷新或关闭页面前保存资料包备份。
4. 在“公告采集”页手动检查官方栏目，或勾选固定资料清单后批量下载。已完整下载的清单资料会复用本机文件。

支持 XLS/XLSX/CSV、TXT/Markdown/HTML、DOCX、文字层 PDF、ZIP；DOC 受系统能力限制。暂不支持扫描件 OCR、RAR/7z、复杂版式完整还原。单文件 20MB，其他读取和下载限制见界面及源代码。

仓库只附带虚构演示文件，不分发真实职位表、用户档案或官网下载附件。“载入演示职位表”在没有本机真实样本时使用虚构资料。

## 专业规则能力

| 策略 | 行为 | 当前边界 |
|---|---|---|
| 广东兼容策略 | 对 A/B/C 代码执行既有上下级初筛 | 不完整覆盖跨学科专业大类、旧名及特殊例外 |
| `hierarchy` | 按有原文证据的显式关系逐级匹配 | 不凭代码相似自动补关系 |
| `enumeration` | 按类别中明确列出的对应学历专业名单匹配 | 不把同列专业互相视作父子专业 |
| `exact` | 同一专业名称、代码或显式别名匹配 | 不扩展上下级 |

后三种策略通过 `gongkao-major-policy` JSON 文件接入，从普通上传入口导入。规则绑定省份、年度、考试类型；冲突、未识别范围及方向限制保留待核对。示例见 [examples](examples/)，**2099 年示例完全虚构**。

当前并未自动把任意 Word/PDF/Excel 目录转换成上述规则文件。需要先人工核对和整理，再导入；规则文件提供的是可审阅的配置，程序不会替你证明配置内容的真实性。

格式与开发说明：[专业规则文件](docs/major-policy-format.md)、[架构](docs/architecture.md)、[开发与验收](docs/development.md)。

## 公告采集边界

- 广东与江苏 2027 的部分固定资料链接已经验证；目录收录不代表全国采集适配完成。
- 批量抓取只处理勾选项；完整且校验正常的本机资料不再联网下载。
- 常规更新读取栏目、复查公告页。页面未变时复用正常附件；补下载失败或损坏项。
- 同一附件 URL 换了文件、公告页却没改，需要主动点击“强制复查正文与附件”。固定清单不自动发现后续更正。
- 遵守 robots 规则、校验 HTTPS、限制下载体积与请求频率，不登录、不提交报名资料。动态页面或访问限制可能导致失败。

## 数据与仓库

个人档案默认不保存；主动保存后位于当前浏览器。页面内资料包刷新后不保留，请自行下载备份。网络采集的正文、附件和版本记录保存在 `data/collector/`。

`data/` 本机资料、`outputs/` 验收与导出、`.vendor/` 本机依赖、历史记录均由 Git 忽略；这些文件保留在使用者自己的电脑上。提交前请执行 [仓库检查](docs/development.md)。

本项目尚未指定源代码开源许可。公开可见与授权他人使用、修改、分发是不同事项；选择许可证后再添加相应 LICENSE。依赖许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
