# 新手安装与使用教程

这是在自己电脑上运行的公考资料整理与岗位初筛工具。准备好环境后，在浏览器里使用；无需购买 AI 服务、填写 AI 密钥或安装数据库。

你可以自己按下面的步骤操作，也可以把 [AI 本地部署指令](ai-local-setup.md) 交给有本机终端和文件权限的 AI 助手。AI 负责安装和启动，之后的筛选操作相同。

## 1. 下载并解压

打开 [GitHub 仓库](https://github.com/ai418033672-svg/gongkao-analyzer)，点击绿色 **Code → Download ZIP**，然后解压。常见文件夹名称是 `gongkao-analyzer-main`。

如果页面提示 404，先确认仓库是否公开；私有仓库需要登录有访问权限的 GitHub 账号。无需为了下载而把账号密码或令牌发给 AI。

进入解压后的文件夹，应该能看到 `server.py`、`requirements.txt` 和 `web` 文件夹。后续命令都要在这个文件夹里执行。不要在 ZIP 预览里运行，也不要直接双击 `web/index.html`。

## 2. 安装 Python

需要 Python 3.9 或以上。已有合适版本可跳过安装。

- **Mac：**打开“终端”，输入 `python3 --version`。
- **Windows：**打开 PowerShell，输入 `py -3 --version`。

如果提示找不到命令，到 [Python 官方下载页](https://www.python.org/downloads/) 安装 Python 3。Windows 安装器若提供 **Add python.exe to PATH**，勾选它。安装后重新打开终端再检查版本。

## 3. 安装项目依赖并启动

下面使用项目专用的 `.venv` 环境，不需要激活环境，也不需要管理员权限。首次安装依赖需要联网。

### Mac

打开终端，输入 `cd `（后面有一个空格），把解压后的项目文件夹拖进终端，按回车。然后逐行执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --open
```

### Windows

在项目文件夹空白处右键，选择“在终端中打开”；使用 PowerShell 执行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py --open
```

如果没有 `py` 命令，但 `python --version` 显示 Python 3.9 或以上，把第一行替换为 `python -m venv .venv`。Windows 步骤按代码入口编写，目前尚未完成 Windows 真机验收。

### 怎样算启动成功

终端会显示类似：

```text
公考分析器已启动：http://127.0.0.1:8765
```

浏览器一般会自动打开。没有自动打开时，把终端显示的完整地址复制到 Chrome 或 Edge。端口被占用时程序会寻找 8765—8775 中的其他端口，以实际输出为准。

看到“选职”和“职位筛选 / 公告采集”页面，就已完成安装。**使用期间保留运行服务的终端窗口。** `127.0.0.1` 指自己的电脑，发给别人不能让对方访问你的页面。

## 4. 先用演示资料走一遍

1. 进入“职位筛选”，展开“资料与自动识别结果”。
2. 点击“载入演示职位表”。干净安装使用仓库内的虚构资料；如果本机另有真实样本，以界面标明的来源状态为准。
3. 查看识别出来的考试省份、年度和类型。仓库 `examples/` 下标注 2099 年的示例也是虚构资料，不是实际招考计划。
4. 在个人条件区域填写学历、学位、专业等已知信息；不知道的项目保持未知，不要为了消除提示而随意选择。
5. 查看职位清单，点击某个岗位的“查看依据”，观察原表来源、条件解释和待核对项。
6. 勾选 2—6 个候选岗位的“加入PK”，点击“PK对比”比较要求；点击“导出当前结果 CSV”保存当前结果。

演示用于熟悉操作，不用于判断自己能报哪个真实岗位。初筛结果只覆盖已读取材料和已填写条件，不能替代招录机关的资格认定。

## 5. 换成自己的真实考试资料

1. 从本次考试的官方网站下载职位表、招考公告、报考指南和专业目录。尽量使用同一省份、同一年度、同一考试的文件。
2. 演示结束后，先“清空资料包”，再点击“＋ 添加文件（可多选）”上传真实资料；也可上传 ZIP。
3. 展开“资料与自动识别结果”，检查省份、年度、考试类型、文件用途，以及是否有冲突、缺页或附件缺失。发现不对时在界面中调整，必要时换用原始文件重新导入。
4. 填写自己的实际条件。专业代码以本次考试目录为准，不要照搬其他省份或其他年度代码。
5. 在“快速缩小结果”中按需要隐藏三不限或不限专业岗位、筛选岗位备注；这些开关只缩小显示范围。
6. 对候选岗位逐个看“查看依据”，核对原文、岗位备注和“地区与共性条件”，再做 PK 和收藏。

支持 XLS/XLSX/CSV、文字层 PDF、DOCX、TXT、Markdown、HTML 和 ZIP。单文件上限 20MB；扫描版 PDF/图片暂不支持 OCR，RAR/7z 需要先自行解压。旧 DOC 在 Mac 依赖系统转换，其他系统建议先转存 DOCX。

专业匹配目前重点验证广东。其他省份可以导入资料、查看原文和使用基础筛选，但不能假定专业规则已经适配。专业目录文件也不会自动变成完整规则；结构化专业规则需要人工整理和证据核对，详见 [专业规则格式](major-policy-format.md)。

## 6. 可选：从“公告采集”获取资料

有官方文件时，直接上传即可；不用先配置采集。

- 点击“公告采集 → 勾选省考资料”，选择需要的固定资料项，按弹窗中的下载操作获取文件。
- 也可以粘贴官网的具体公告或附件地址，选择对应链接类型，再点击“一键抓取”。动态专题或访问限制可能导致失败，失败时从官网下载文件后上传。
- 默认只看近 30 天、未截止或时间待核对的内容。找不到历史记录时，点击“查看全部历史”，或调整日期与报名状态。
- 资料采集后，按记录提供的操作带入职位筛选，并继续检查读取结果。目录收录不等于全国都能自动采集；当前只验证了广东、江苏的部分固定链接。

## 7. 保存、关闭与下次使用

**关闭或刷新页面之前，先点击“保存资料包”。** 下次启动后用“恢复资料包”导入保存的 JSON。资料包包含导入文字与岗位，应像原始报考材料一样妥善保存。

“导出当前结果 CSV”只保存筛选结果，不能代替完整资料包备份。“仅在此浏览器记住我的档案”是可选项，换浏览器或清理浏览器数据可能丢失。包含个人档案的导出请自行保管，不要提交到 GitHub。

停止服务：回到运行服务的终端，按 `Ctrl+C`。关闭网页本身不会停止服务。

下次无需重新安装依赖，进入项目文件夹后执行：

```sh
# Mac
.venv/bin/python server.py --open
```

```powershell
# Windows PowerShell
.\.venv\Scripts\python.exe server.py --open
```

也可尝试双击项目中的对应启动器；首次安装仍按上述步骤完成。Mac 下载文件若缺少执行权限，使用终端命令启动即可。

## 常见问题

| 现象 | 处理方法 |
|---|---|
| 找不到 `requirements.txt` 或 `server.py` | 当前不在项目根目录；进入能看到这两个文件的文件夹后再执行。 |
| 提示缺少 `xlrd`、`pypdf` 等模块 | 用上面 `.venv` 中的 Python 重新执行依赖安装，并用同一个 Python 启动。 |
| 依赖下载失败、超时 | 检查网络，保留错误提示后重试；不要跳过依赖安装而声称部署完成。 |
| 浏览器打不开或刷新后失效 | 确认终端中的服务仍在运行，使用终端显示的实际地址；不要使用 `file://` 地址。 |
| 所有默认端口都被占用 | 在启动命令末尾加 `--port 8789`，使用新输出的地址。不要强行结束不认识的进程。 |
| 有岗位但专业判断待核对 | 先检查考试归属、目录和规则覆盖范围；未适配规则不能当作符合或不符合。 |
| 扫描 PDF 读不到文字 | 使用官方文字版文件，或自行 OCR 后检查文字，再导入可读文件。 |
| 采集页找不到某份资料 | 检查日期/报名状态过滤，尝试具体公告链接；仍失败就官网下载后上传。 |

更多能力边界见 [README](../README.md)；开发测试见 [开发说明](development.md)。
